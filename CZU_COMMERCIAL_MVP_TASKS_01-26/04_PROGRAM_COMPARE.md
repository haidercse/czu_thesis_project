# 04 --- Program Comparison

## Objective

Complete and improve program comparison.

## Existing Direction

The project has a comparison foundation and the remaining task
specification supports comparing up to 5 programs using sessionStorage.

## Requirements

-   Support up to 5 programs.
-   Prevent duplicate programs.
-   Add/remove programs easily.
-   Preserve selected programs during normal navigation where practical.
-   Compare available fields such as:
    -   University
    -   Program
    -   Degree
    -   Language
    -   Tuition/fees
    -   GPA/academic requirements when available
    -   Application deadline
    -   Application fee when available
    -   City
-   Clearly show unavailable data instead of inventing values.
-   Keep the comparison readable on mobile.

## Deliverables

Comparison UI, JavaScript/state handling, route/controller updates if
needed, and tests.

## Completion Criteria

A student can compare up to five existing programs without duplicating
data or breaking existing search functionality.
