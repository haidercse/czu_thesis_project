# 11 --- Deadline Engine

## Objective

Make application deadlines useful throughout the student workflow.

## Requirements

-   Use existing program/application deadline fields where available.
-   Display deadlines on program details and application workspace.
-   Identify upcoming deadlines.
-   Clearly distinguish missing/unknown deadlines.
-   Avoid timezone confusion.
-   Do not fabricate dates.
-   Prepare the data structure for future reminders.

## Suggested Categories

-   Deadline passed
-   Due soon
-   Upcoming
-   No deadline recorded

Use existing terminology if the project already has status labels.

## Completion Criteria

Students can see important deadlines in the places where they make
application decisions.
