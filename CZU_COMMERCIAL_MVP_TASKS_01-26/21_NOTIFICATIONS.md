# 21 --- Notifications

## Objective

Add useful application-related notifications after the core workflow is
stable.

## Notification Types

Potential notifications: - Upcoming application deadline - Missing
required document - Document review result - Checklist update - Profile
incomplete - Application status change

## Requirements

-   Inspect existing notification/email infrastructure first.
-   Avoid notification spam.
-   Support queue-based delivery later if needed.
-   Keep in-app state understandable.
-   Do not send deadline notifications when the deadline is unknown.

## Completion Criteria

Notifications help students act on concrete application tasks rather
than generating noise.
