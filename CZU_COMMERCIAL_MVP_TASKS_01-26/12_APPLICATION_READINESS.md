# 12 --- Application Readiness

## Objective

Add a transparent readiness indicator for each application.

## Inputs

Possible inputs: - Checklist completion - Required documents uploaded -
Required documents approved, if verification exists - Profile
completeness - Missing application information - Deadline availability

## Requirements

-   Make the calculation explainable.
-   Do not present readiness as admission probability.
-   Do not use unsupported weighting.
-   Show exactly what is preventing an application from being ready.
-   Recalculate when relevant application data changes.

## Completion Criteria

The student can answer: "What is still missing before I can submit this
application?"
