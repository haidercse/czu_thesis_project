# 24 --- Analytics

## Objective

Add product analytics that help improve the platform and understand
application workflow usage.

## Useful Metrics

Examples: - Program searches - Program detail views - Saved programs -
Comparisons - Applications created - Checklist progress - Document
uploads - Application completion - Deadline interactions

## Privacy

-   Collect only necessary data.
-   Avoid exposing private student documents or unnecessary personal
    information.
-   Define retention/access rules.

## Admin Reporting

Where useful, support summary dashboards and CSV/Excel export.

## Completion Criteria

Analytics provide actionable product information without compromising
student privacy.
