# 13 --- Saved Programs

## Objective

Allow students to save programs they want to revisit.

## Requirements

-   Inspect whether favorites/saved programs already exist.
-   If absent, implement a simple persistent relationship between User
    and Program.
-   Prevent duplicate saves.
-   Allow unsave.
-   Add a saved-programs page or suitable dashboard section.
-   Preserve existing search and program detail pages.
-   Handle deleted/inactive programs safely.

## Suggested Use

Saved programs can later feed recommendations and application creation.

## Completion Criteria

A student can save a program from search/detail pages and later find it
easily.
