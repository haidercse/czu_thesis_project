# 17 --- Official Source Verification

## Objective

Improve trust in university and program information.

## Requirements

Add or reuse fields such as: - Official source URL - Last verified
date - Verification note/status where useful

## Admin Workflow

Admins should be able to record when program information was checked
against an official source.

## Student UI

Show a clear link to the official university/program source and, where
appropriate, when the platform information was last verified.

## Rules

-   Do not imply the platform is the university.
-   Do not claim information is current if it has not been verified.
-   Do not invent official URLs.

## Completion Criteria

Students can distinguish platform information from official university
information.
