# 10 --- Recommendation Engine

## Objective

Improve program recommendations using transparent rules before
introducing advanced AI.

## Inputs

Use available profile preferences such as: - Target field - Degree -
Language - Budget - City - Intake - Academic profile - Eligibility
information

## Requirements

-   Reuse the existing recommendation foundation.
-   Prefer rule-based matching first.
-   Explain why a program was recommended.
-   Do not guarantee admission.
-   Do not present recommendations as official university decisions.
-   Avoid scoring dimensions that cannot be supported by available data.

## Future Direction

Advanced AI recommendations may be added later, but only after the
underlying program data is reliable.

## Completion Criteria

Recommendations are understandable, reproducible and based on actual
stored data.
