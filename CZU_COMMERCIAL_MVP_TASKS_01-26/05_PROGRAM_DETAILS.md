# 05 --- Program Details

## Objective

Improve the program detail page so a student can make an informed
application decision.

## Information

Show available data for: - University - Program name - Degree level -
Study language - Tuition/fees - Application fee - Admission
requirements - Academic requirements - Language requirements -
Application deadline - Intake - City/location - Official
university/program URL - Other existing relevant fields

## Data Integrity

-   Do not invent missing requirements.
-   Clearly label unavailable information.
-   Add source/verification metadata where supported by the database.
-   Link students to the official source for final confirmation.

## Requirements

Inspect the existing Program model, migration and views before modifying
them.

## Deliverables

Improved detail view and required backend/data changes.

## Completion Criteria

A student can understand the key application information from one page
and can reach the official source for confirmation.
