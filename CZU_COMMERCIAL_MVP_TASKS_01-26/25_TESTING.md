# 25 --- Testing

## Objective

Build reliable automated coverage for the commercial MVP.

## Priority Areas

Test: - Authentication/authorization - Profile validation - Program
search/filtering - Program comparison - Saved programs - Eligibility
rules - Recommendations - Applications - Checklist personalization -
Document upload/integration - Document ownership/security - Admin CRUD -
Deadline logic - Readiness calculation - Payment entitlements when
implemented

## Requirements

-   Inspect existing test suite before adding tests.
-   Prefer focused feature/unit tests.
-   Do not create brittle tests tied unnecessarily to HTML structure.
-   Test authorization failures as well as successful paths.

## Completion Criteria

Critical student and admin workflows have automated coverage and the
suite passes consistently.
