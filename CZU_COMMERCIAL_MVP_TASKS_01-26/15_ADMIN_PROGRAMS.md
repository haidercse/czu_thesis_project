# 15 --- Admin Programs

## Objective

Improve the existing admin program management.

## Requirements

-   Preserve current Program CRUD.
-   Validate university relationships.
-   Validate required fields.
-   Make deadline, fee, language, degree and requirement fields
    manageable where supported.
-   Support official URL/source data.
-   Avoid duplicate programs where appropriate.
-   Improve edit/create usability.
-   Protect related data integrity.

## Data Integrity

Admin forms must not allow malformed values that later break search,
comparison or recommendations.

## Completion Criteria

Program records maintained by admins are structured enough for all
student-facing features.
